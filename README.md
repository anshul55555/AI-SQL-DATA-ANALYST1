# AI SQL Data Analyst Agent

## 🚀 Features
- Upload CSV
- Convert to SQL
- Ask questions in natural language
- Auto SQL generation
- Visualization

## 🛠 Setup

```bash
pip install -r requirements.txt
```

## ▶️ Run

```bash
streamlit run app.py
```

## 🔑 Setup API Key

Replace:
```
YOUR_GROQ_API_KEY
```

with your actual Groq API key.
